# SK 7mobile 변경 감지 수정

검증일: 2026-10-12 (KST)

## 원인

- 기존 이미지 선택자는 실제 `.bbs-view .view-body .eventCont`를 인식하지 못해 넓은 `#ct` 영역으로 내려갔다. 실제 상세 이미지 외에 공통 띠배너와 추천 이벤트 이미지를 수집했다.
- 다운로드 하나가 실패하면 전체 해시를 폐기했다. 실패 캐시를 이벤트끼리 공유해 같은 리소스의 일시 실패가 여러 이벤트의 경고로 전파됐다.
- `collection_warnings()`가 `_image_collection_error` 및 보존한 해시를 이벤트별 경고로 표시했다. 스크린샷의 문구는 이 경로에서 생성된다.
- 2026-10-12 수집본 및 실행 38180461724에서 반복 실패를 확인했다. 당시 로그는 실패 URL/예외 종류를 버려서 과거 HTTP/TLS/timeout 중 정확한 원인은 확인할 수 없다. 수정 후 진단에는 URL과 예외 종류가 남는다.
- 조회수 필터는 `조회 123` 또는 한 줄의 `조회수 123` 일부만 처리했고 D-day 비교 필터가 경로별로 달랐다. 반대로 날짜만 있는 텍스트를 제거해 실제 기간/유의사항 날짜를 놓칠 수 있었다. HTML 주석과 챗봇 등 페이지 외곽도 본문에 섞였다.

## 변경

- `promotion_noise.py`: 수집/본문 비교/제목 비교/유의사항 비교/CSV 정제에서 사용하는 공통 필터. 조회수, D-day, 남은 일수 및 수집 메타데이터만 제외한다. 날짜, 30일 이내 지급, 12개월 유지 등 실제 조건은 보존한다.
- `content_extractor.py`, `main.py`: SK7 상세 영역으로 텍스트 범위를 한정하고 주석/공통 띠배너/카운터를 제거한다. 실제 이벤트 기간을 `event_period`에 별도로 저장한다. 제목의 실제 날짜도 보존한다.
- `detail_image_monitor.py`: 상세 이미지에 한정한 실제 바이트 SHA-256 비교. 동일 URL의 이미지 교체를 감지한다. 24개 상한을 넘으면 부분 집합을 정상 기준으로 삼지 않는다. 실패는 비교 기준을 보존하며 진단을 기록한다.
- `monitor_core.py`: 이미지 실패에 대한 이벤트별 반복 사용자 경고를 제거한다. 다른 본문/유의사항/회사 수집 실패 경고는 유지한다. 새 추출 범위의 최초 본문/이미지 관측은 기준을 새로 설정해 범위 변경 자체의 오탐을 방지한다. 기존 본문의 기간이 있으면 첫 전환에서도 기간 변경을 비교한다.
- `parser.py`: 변경 건수, 짧은 변경 종류, 기간 변경 전후, 대표 확인 링크를 표시한다. 유의사항의 원문과 추가/삭제 줄 수 대신 짧은 핵심을 표시한다. Slack 링크/미디어 자동 미리보기를 끈다.
- `Home.py`, 프로모션 변경 리포트 페이지: 기존 Streamlit 모듈 캐시도 새 규칙으로 갱신한다. 상세 이미지/이벤트 기간 변경을 화면에 표시한다.

## 검증

- 전체 회귀 테스트 55개 통과. 카운터 표기/분리된 HTML, 실제 기간·날짜·유지조건, 해시 교체, 기준 보존, 범위 전환, Slack 미리보기 비활성화 및 기존 크롤러 회귀를 포함한다.
- 첨부 경고의 상세 페이지 7개를 읽기 전용으로 검증: 유효 상세 이미지 33개, 실패 0개. 각 이미지를 다시 다운로드해 2회 결과가 동일함을 확인했다.
- 원격 이미지를 실제로 수정하지 않았다. 동일 URL 바이트 교체는 모의 응답 회귀 테스트로 검증했다.
- Slack 전송은 모의 HTTP 응답으로 검증했다. 실제 채널에 테스트 알림을 보내지 않았다.

## 제약

- 해시 비교는 이미지 파일이 바뀌었다는 사실만 확인한다. OCR이 없으므로 이미지 속 금액/날짜/문구를 전후 요약하지 못한다. 파일 재인코딩도 변경으로 감지될 수 있다.
- 외부 CSS가 생성하는 배경 이미지, canvas 및 iframe 이미지까지 수집하지 않는다. DOM 이미지/lazy-src/srcset/인라인 배경을 지원한다.
- 네트워크 실패 시 변경을 확정하지 않고 이전 기준을 유지한다. 이미지 진단은 저장된 스냅샷과 실행 로그에서 확인한다.
- 새 범위의 최초 본문/이미지 비교는 기준 설정이다. 기존 범위와 비교해 그 사이의 이미지/본문 변경을 확정할 수 없다. 이후 수집부터 정상 비교한다.
- 로컬 전체 테스트는 Python 3.14에서 기존 크롤러 의존성 호환을 위해 테스트 전용 setuptools를 초기화해 실행했다. GitHub 회귀 워크플로는 저장소의 Python 3.9 환경을 사용한다.
