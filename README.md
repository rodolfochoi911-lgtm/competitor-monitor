# competitor-monitor

## 예약 실행

예약 시각은 UTC로 설정되어 있으며 한국 시각으로 환산하면 아래와 같습니다.

- 프로모션: 매일 06:07 / 15:12 KST
- 시장 조사: 매일 06:00 KST, 전일 게시글 수집

2026-09-08 예약 실행 기록에서 시장 조사는 08:21:55, 프로모션은
08:24:40 KST에 실행이 생성됐습니다. 생성 후 runner 시작은 각각 3초와 2초였으므로
주된 지연은 crawler가 아니라 GitHub의 예약 실행 생성 이전에 발생했습니다.
프로모션 수집은 이후 약 23분이 더 걸렸습니다.

GitHub Actions schedule은 정시 실행을 보장하지 않습니다. 정확한 시각이 필수라면
외부 스케줄러에서 workflow_dispatch를 호출하는 운영 방식이 필요합니다.
이번 변경에서는 원래 예약 시각을 유지하고 실행 요약에 예정/실제 진단 시각을 기록합니다.
https://docs.github.com/en/actions/how-tos/troubleshoot-workflows

## 데이터 보호와 검증

수집 장애·페이지 한도·구조 변경은 정상 0건으로 저장하지 않고 실패로 처리합니다.
실패한 실행의 데이터 커밋과 후속 배포는 실행하지 않습니다. 예약 실행은 기존 알림 설정을 사용합니다.
회귀 테스트는 외부 크롤링/알림 없이 `python -m unittest discover -s tests -v`로 실행합니다.

혜택 시뮬레이터와 미산출 금액 차트는 제거했습니다. 본문·유의사항은 이벤트별로 비교하며 숫자·날짜 조건과 원문 URL을 보존합니다.
